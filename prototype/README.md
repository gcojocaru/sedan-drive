# Russian Hill prototype assets

The map picker offers midday and rainy dusk at Lombard and Larkin in San Francisco. Both views use the same bundled geometry, driving lanes, elevation, and starting direction. The southwest curb, drainage and house finishes are a visual study. Their materials and architectural details are interpreted.

- The bundled street and building database is © OpenStreetMap contributors, distributed under the [Open Database License](https://www.openstreetmap.org/copyright). The source is the [OSM map extract](https://api.openstreetmap.org/api/0.6/map?bbox=-122.4284,37.7969,-122.4156,37.8071). The gzip file contains filtered nodes and ways, with way coordinates stored as latitude/longitude pairs.
- The elevation grid is sampled with the game's terrain filter from [Mapzen Terrarium](https://github.com/tilezen/joerd/blob/master/docs/attribution.md), zoom 12, tile 655/1582.
- The asphalt colour, OpenGL normal and roughness maps are resampled from [Poly Haven Asphalt 04](https://polyhaven.com/a/asphalt_04), released under [CC0](https://creativecommons.org/publicdomain/zero/1.0/).
